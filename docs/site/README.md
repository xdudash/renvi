# Страницы RENVI для сайта naoberuky.com

Загрузите папки `privacy`, `terms`, `community` (из `docs/site/dev/apps/renvi/`) на Hostinger в `public_html/dev/apps/renvi/`.
Получатся адреса:

- https://naoberuky.com/dev/apps/renvi/privacy/index.html
- https://naoberuky.com/dev/apps/renvi/terms/index.html
- https://naoberuky.com/dev/apps/renvi/community/index.html

Затем впишите их в админке (Настройки → Документы). Страницы на английском, как и весь сайт. Перед публикацией юрист должен
их просмотреть (особенно разделы про сроки хранения и ответственность).
